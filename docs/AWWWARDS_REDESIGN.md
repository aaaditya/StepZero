# Awwwards / Linear creative redesign notes

Brutal critique + remediations shipped on branch
`cursor/awwwards-homepage-redesign-9169`. Brand tokens preserved.

## What felt generic

| Area | Weakness | Why it fails |
|---|---|---|
| Hero headline | 3-line “Starts at” break | Reads unfinished; brand delayed |
| Hero subhead | Deliverable menu | Lists services, not outcomes |
| Trust chips | SaaS checkboxes | Interchangeable with every agency |
| Missing strip | No POV between hero & method | No spine before systems |
| Industries | Icon grid | Template agency; blueprint rejected |
| Testimonials | Material quote cards | Quote in secondary gray = low trust |
| Why-us | 6 rows, no CTA, “vs” pills | Fatigues; no conversion capture |
| Process | Launch/Grow; thin detail | Lost “Compound”; black-box feel |
| Final CTA | “Leave Step Zero?” | Semantic conflict with brand name |
| CTA labels | Inconsistent across page | Raises conversion friction |
| Placeholders | Empty gradients | Premium craft claim collapses |

## What we redesigned

1. **Hero** — “We build businesses / people trust.” Outcome subhead. Accent pill. Editorial trust dots. Unified CTAs: “Start a project” / “View our work”.
2. **Trust conviction strip** — three POV statements under the hero.
3. **Transformation** — “The Method”; outcomes replace gradient placeholder; `00` indexing.
4. **Systems** — distinct eyebrow/title; “Learn more →”.
5. **Featured work** — UI-filled device mocks; bordered metrics; secondary case CTA; aligned max width.
6. **Industries** — interactive list + atmospheric panel (no icon grid).
7. **Why StepZero** — 4 decisive rows; left-aligned StepZero claims; mid-funnel CTA.
8. **Process** — 5 stages ending in **Compound**; involvement copy; line starts on build.
9. **Testimonials** — editorial typography, not cards; primary text color.
10. **Arc** — Work → Industries → Why → Process → Testimonials → FAQ → Insights → CTA.
11. **Final CTA** — “Ready to become the brand people trust?” Diagnostic invite; scarcity without “serious inquiries only”.
12. **Insights** — typographic featured panel; text-forward rows.
13. **Nav** — wider link spacing.
